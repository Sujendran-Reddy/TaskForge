# TaskForge

TaskForge is a full-stack project management application built with React, TypeScript, ASP.NET Core, Entity Framework Core, PostgreSQL and Docker.

It allows users to log in, create workspaces, create projects, create tasks, and move tasks across a Kanban board.

## Features

- User registration
- User login
- JWT authentication
- BCrypt password hashing
- Protected API routes
- User-specific workspaces
- Workspace roles
- Project creation
- Task creation
- Task priorities
- Kanban task statuses
- Drag and drop task movement
- PostgreSQL database persistence
